# Architecture
See [visual atlas](visual-atlas.md). Layers: upstream universal factory, ERP domain, vendor, landscape archetype, private customer, work item. Separate development plane (code, tests, transports), runtime integration plane (deterministic transactions) and governed agent access plane. Customer-hosted workers preferred for restricted environments. Authority external to model; portable skills and JSON contracts; no direct production execution in prototype. EVOLVE loops request-to-release, issue-to-fix, opportunity-to-expansion plus experience-to-better-factory. First target supervised L3 for a bounded change class, not entire ERP.
