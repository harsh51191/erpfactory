# Support and learning
Observe across SAP, middleware and external apps; correlate messages and business documents. Monitor authorized logs, jobs, queues, Gateway, IDoc, middleware and ALM where applicable. Diagnose before retry; reconcile timeout-after-commit; known recovery only within policy. L1 classify, L2 diagnose/reprocess, L3 governed fixes, L4 vendor escalation. Define SLA, support hours, owners, emergency stop, runbooks and warranty. No 24x7 promise without staffing. Lessons must become candidate tests, evaluated on held-out data before promotion.
