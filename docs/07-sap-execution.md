# SAP execution and policy
ECC AnyDB, ECC HANA, S/4 on-prem/private/public are distinct; HANA is a database, S/4 is an application. Discover actual release, Gateway, middleware and authorization. Candidate APIs, BAPIs/RFC/IDoc, CDS/ADT, CTS, PI/PO and Integration Suite depend on edition. [SAP API policy](https://help.sap.com/doc/sap-api-policy/latest/en-US/API_Policy_latest.pdf) and customer contract must be reviewed per pathway; do not bypass controls with proxies, GUI or custom MCP. Official tools are not blanket permission. Use released APIs first. Signavio, LeanIX, Cloud ALM optional; verify existing entitlements. No live SAP adapter implemented.
Labs: [API Hub](https://api.sap.com/), [BTP trial](https://www.sap.com/products/technology-platform/trial.html), [CAL](https://cal.sap.com/). Basic trial is not full integration sandbox. Reference appliance has hosting charges and licence terms; planning allowance INR 20–45k including contingency, not quote. Recheck current entitlements, availability and actual cost before purchase.
