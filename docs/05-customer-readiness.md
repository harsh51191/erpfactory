# Customer readiness
Collect ERP version/database/deployment, middleware, modules, integrations, customizations, DEV/QA/UAT/PROD, refresh and masked data, network, identities, licensing, capacity, security and support. Firewall matrix: source/destination host, port/protocol, direction, environment, purpose, auth, owner, expiry and actual probe result. Verify DNS, TCP/TLS, authentication, operation-specific authorization, environment and data route. No broad access. Distinguish declared/verified/blocked/unknown.
Sign-off: business owner requirements/UAT; ERP architect design; functional lead semantics; independent technical reviewer; security authority access; release authority production; service owner outcomes. Name backup and escalation. Discover TR types, routes, object locks, sequence, release/import permissions and recovery; public cloud differs. Baseline CPU/RAM/DB/storage/work processes, peak API/message volumes, retention, retries, throttling. Confirm developer seats, digital access, BTP/middleware entitlements, test systems and incremental costs with customer commercial owner. No purchase without evidence.
