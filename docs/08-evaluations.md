# Evaluation beyond coding
Start with [ABAP compiler feedback study](https://arxiv.org/abs/2601.15188) and [benchmark](https://github.com/timkoehne/LLM-Benchmark-ABAP-Code-Generation), then extend beyond algorithmic code. Measure first-pass and post-feedback success, time, cost, intervention, false positives and safety violations. Compare same task, environment, tools, budget, exact model version and held-out set.
Suites: discovery coverage, targeted clarification, change placement, API compatibility, cross-module dependency recall, functional transaction correctness, regression detection, authorization, transport, performance, recovery, support diagnosis, skill learning and portability. Hard safety failures cannot be averaged away. Test negative controls and ambiguous writes. Synthetic proof never equals live SAP proof. First synthetic cases in tests/; independent runner and live campaign not yet built.
