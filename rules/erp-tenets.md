# ERP tenets
All rules are proposed until enforced and verified; no agent may relax them.
| ID | Rule | Gate |
|---|---|---|
| ERP-00 | Vendor terms and customer authorization both apply | Approved pathway |
| ERP-01 | Discover before changing | Landscape evidence |
| ERP-02 | Mine first, interview second | Evidence-backed questions |
| ERP-03 | Never assume standard implementation | Release and configuration fingerprint |
| ERP-04 | Standard before custom | Change placement |
| ERP-05 | Understand dependencies before mutation | Impact report |
| ERP-06 | Evidence over confidence | Proof record |
| ERP-07 | Validate early | Static, mock, live probes |
| ERP-08 | Preserve existing behaviour | Regression baseline |
| ERP-09 | Verify business outcomes | Read-back and reconciliation |
| ERP-10 | Security by design | Deterministic authority |
| ERP-11 | Recoverability | Tested compensation or restore |
| ERP-12 | Failure creates learning | Lesson and regression case |
| ERP-13 | Earn autonomy | Scoped independent evidence |
| ERP-14 | Isolate customer knowledge | Private tenant store |
| ERP-15 | Model independence | Common executable contract |
| ERP-16 | Optimize outcomes per human hour | Outcome metrics |
| ERP-17 | Prove access before delivery commitment | Connectivity preflight |
| ERP-18 | Representative test environment | Environment gate |
| ERP-19 | Named decision owners and backups | Sign-off matrix |
| ERP-20 | Clean core and correct system ownership | Placement decision |
| ERP-21 | Cross-module impact | Dependency graph |
| ERP-22 | Supportability | Operational readiness |
| ERP-23 | Respect transport lifecycle | Release gate |
| ERP-24 | Resource and cost budget | Capacity tests |
| ERP-25 | Licensing is architectural | Entitlement sign-off |
| ERP-26 | Reuse existing customer tooling | Tool inventory |
| ERP-27 | Fast iterations without reduced assurance | Continuous tests |
| ERP-28 | Runtime portability | Cross-runtime eval |
| ERP-29 | Unknown is not safe | Discovery coverage |
| ERP-30 | Customer ownership and exitability | Handover and export |
